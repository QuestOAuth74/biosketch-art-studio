---
name: No auto-commit
description: Never commit or push without explicit user permission — always ask first
type: feedback
---

Never commit or push code without explicit permission from the user. Always ask first.

**Why:** User wants to test all changes in dev mode before committing. Commits should only happen when the user explicitly says "commit" or "push".

**How to apply:** After completing code changes, tell the user they can test. Wait for their confirmation that everything works before offering to commit. Never auto-commit after completing a task.
